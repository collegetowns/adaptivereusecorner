🔧 Builder

This page is only for you. It opens when the address ends in #builder and isn't linked anywhere. Anything you change here is saved in this browser until you click Download updated app at the bottom.

📬 Suggestions inbox

Option A: through the visitor's own email. Enter the address that suggestions should go to. When a visitor submits, Gmail or their email app opens with the suggestion filled in, and they press Send. The address is disguised in the page so it's harder for spam bots to collect.

Option B (optional): sent automatically, no email app needed. If you set this up, it's used instead of Option A. Suggestions are emailed to you through Formspree, a free form service. To turn it on, create a free account and a new form, then paste the form's ID or its endpoint link (https://formspree.io/f/xxxxxxx) here.

✅ Approve a suggestion

Each suggestion email ends with an approval code starting with ARC1:. Paste it here to fill in the Add a property form below. Check the details, give it a name and description, and click Add property. To skip a suggestion, just ignore the email.

Turn on in-app Street View

Satellite and map views work right away. To show Street View inside the cards, Google needs a free Maps Embed API key. The Embed API has no usage charges.

  1. Go to console.cloud.google.com/google/maps-apis and sign in.
  2. Create a project and enable the Maps Embed API.
  3. Under Keys & Credentials, create an API key and paste it below.

The key is saved only in this browser. Before you put the site online, restrict the key to your website's address in Google Cloud.

🔧 Builder tool: lock in exact locations

This looks up each new property's exact address, finds the nearest Street View photo and aims the camera at the building. It costs about one lookup per property and skips any property already locked in. Visitors then get Street View through the free Embed API.

It needs the Maps JavaScript API and Geocoding API enabled on your key. They only need to be on while you run this.
